## 🚀 Deploy to GitHub Pages — Step by Step

### Step 1: Create a GitHub Organization

1. Go to [github.com](https://github.com) → click your profile picture → **"Your organizations"**
2. Click **"New organization"**
3. Choose **Free plan**
4. **Organization name:** `mairilab` *(or `mairi-institute`)*
5. Complete setup → click **"Create organization"**

---

### Step 2: Create Repository inside the Organization

1. Inside the `mairilab` organization → click **"New repository"**
2. **Repository name:** `mairilab.github.io`
   > ⚠️ Must match the organization name exactly for GitHub Pages root URL
3. Set to **Public**
4. Click **"Create repository"**

---

### Step 3: Upload Files

1. Open the new repo → click **"uploading an existing file"**
2. Extract the ZIP and drag-drop:
   ```
   index.html
   css/style.css
   js/main.js
   README.md
   ```
3. Commit message: `Initial MAIRI site deploy`
4. Click **"Commit changes"**

---

### Step 4: Enable GitHub Pages

1. Go to repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** | Folder: **/ (root)**
4. Click **Save**

---

### Step 5: Live!

Wait 2–3 minutes, then visit:
> ### `https://mairilab.github.io`
